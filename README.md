# GAM — Городская автомобильная мастерская

Android-приложение для общения клиента и автосервиса в тёмном современном стиле с салатовыми акцентами.

## Тестовая версия
- Android 7.0+ (minSdk 24)
- targetSdk 35 (Android 15)
- нативный Android WebView-контейнер
- launcher-иконка GAM
- чат с локальным сохранением
- запись на сервис
- карточка ремонта и согласование сметы
- демонстрационный онлайн-канал по коду мастерской

## Проверка APK
GitHub Actions собирает APK через официальный Android Gradle Plugin и затем проверяет:
- цифровую подпись через apksigner;
- targetSdkVersion 35;
- наличие запускаемой ru.gam.app.MainActivity через aapt dump badging.

Перед массовой раздачей клиентам демонстрационный онлайн-канал нужно заменить на собственный защищённый backend и добавить полноценные аккаунты/push-уведомления.
